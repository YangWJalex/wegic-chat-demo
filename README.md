# Wegic 对话演示 Demo

这是一个模仿微信聊天界面的对话演示demo，展示了心理咨询师Z与Wegic之间的24个分镜对话场景。

## 功能特点

- 🎨 **微信风格界面**：完全模仿微信的聊天界面设计
- 💬 **24个精心设计的分镜**：展示完整的咨询服务对话流程
- 🎮 **分镜控制**：
  - 进度条拖动快速跳转
  - 前进/后退按钮逐镜查看
  - 播放/暂停自动播放功能
- 📱 **响应式设计**：适配不同屏幕尺寸
- ✨ **多种消息类型**：
  - 普通文本消息
  - 链接消息
  - 选项chips
  - 卡片展示
  - 表单输入
  - 进度展示卡

## 技术栈

- React 18
- TypeScript
- Tailwind CSS
- Vite
- Framer Motion
- Lucide React (图标)

## 使用说明

1. **查看分镜**：页面加载后会显示第一个分镜的对话内容
2. **手动控制**：
   - 点击底部的"上一个"/"下一个"按钮切换分镜
   - 拖动进度条快速跳转到指定分镜
3. **自动播放**：点击中间的播放按钮，系统会自动每3秒切换一个分镜
4. **查看详情**：底部会显示当前分镜的标题和描述信息

## 分镜说明

Demo包含24个分镜，展示了以下SOP（标准操作流程）：

- **SOP1**：需求收集与理解
- **SOP3**：共情与复述
- **SOP4**：提供选项降低表达成本
- **SOP5**：价值观对齐
- **SOP6**：分页确认与信息采集
- **SOP7**：导游式引览
- **SOP8**：预期管理

每个分镜都精心设计了对话内容，展示了如何通过对话引导用户完成网站设计需求的收集。

## 自定义修改

### 修改分镜内容

编辑 `src/data/scenes.ts` 文件，可以修改现有分镜或添加新的分镜。

### 修改自动播放速度

在 `src/App.tsx` 中修改 `setTimeout` 的延迟时间（默认3000毫秒）。

### 修改主题颜色

在 `src/index.css` 和组件中修改微信绿色主题色：
- `#95EC69` - 用户消息气泡背景
- `#07C160` - 主题色（按钮、进度条等）
